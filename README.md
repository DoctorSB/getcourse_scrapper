# GetCourse Scraper

Скачивает видео из курсов на getcourse.ru, к которым у вашего аккаунта уже есть
доступ, и при желании перекладывает их на Яндекс Диск. Управляется через
локальный веб-интерфейс или из терминала.

Форк [nqxcode/getcourse-ru-web-scraper](https://github.com/nqxcode/getcourse-ru-web-scraper):
PhantomJS заменён на Playwright (headless Chromium), поэтому проект работает на
современных страницах getcourse, на Apple Silicon и в Docker под arm64 и amd64.

- **Интерфейс** — вход, выбор уроков, прогресс по каждому файлу.
- **Автосбор уроков** — скрипт сам находит ваши курсы и строит список.
- **Докачка** — после прерывания недокачанное продолжается, готовое пропускается.
- **Яндекс Диск** — локальная копия удаляется только после проверки на Диске.

## Быстрый старт

### Docker

Скрапер, интерфейс и выгрузка работают в одном контейнере.

```sh
cp .env.sample .env                   # указать SCRAPPER_BASE_URL и SCRAPPER_TRAINING_CONFIG_DIR
touch auth-state.json yadisk-auth.json
docker compose up -d --build
open http://127.0.0.1:4321
```

`touch` нужен при первом запуске: иначе Docker создаст на месте этих файлов папки.

Логи — `docker compose logs -f`, остановка — `docker compose down`. Видео попадают
в `./download`. `config/trainings`, `logs` и файлы авторизации смонтированы с
хоста, поэтому пересборка ничего не теряет.

**Вход в контейнере — только по cookie**, окно браузера там открыть негде. Войдите
на сайт в обычном браузере, в DevTools → Application → Cookies скопируйте имя и
значение cookie сессии (обычно `PHPSESSID5`) и вставьте в раздел «Вход по cookie».
Другой вариант — войти на хосте через `npm run login`: `auth-state.json` общий.

**Доступ к сайту.** Если сайт открывается только через обход блокировки на хосте,
из контейнера он может быть недоступен. Проверка:

```sh
docker compose exec scraper curl -sS -o /dev/null -w '%{http_code}\n' --max-time 15 https://ваш-сайт.ru
```

Пусто или таймаут — качайте на хосте, выгрузку можно оставить в контейнере.

### Локально

Нужны Node.js, `ffmpeg` и `yt-dlp`.

```sh
brew install ffmpeg yt-dlp            # или аналог для вашей системы
npm install
npx playwright install chromium
cp .env.sample .env
npm run ui                            # http://127.0.0.1:4321
```

Дальше всё кнопками: вход, поиск курсов, выбор уроков, загрузка и выгрузка на Диск.

## Терминал

То же самое без интерфейса. В `.env` должны быть заполнены `SCRAPPER_BASE_URL` и
`SCRAPPER_TRAINING_CONFIG_DIR`.

```sh
npm run login        # 1. войти в окне браузера; капча, СМС и 2FA работают
npm run discover     # 2. собрать уроки в config/trainings/<сайт>/trainings.json
./cmd/run.sh         # 3. скачать всё из этого списка
```

Если автопоиск не нашёл курсы, передайте адреса явно, можно несколько:

```sh
npm run discover -- https://ваш-сайт.ru/teach/control/stream/view/id/123456
```

`trainings.json` — обычный JSON: лишние уроки можно удалить, а `title` станет именем
папки. Перед перезаписью файл бэкапится рядом с собой.

```json
[
  {
    "title": "Название курса",
    "paths": [
      "/teach/control/lesson/view/id/157209236",
      "/teach/control/lesson/view/id/157209275"
    ]
  }
]
```

Лог запуска — `logs/<дата>/scraper.log`, симлинк `scraper.log` ведёт на последний.
Прервать можно через Ctrl-C.

## Выгрузка на Яндекс Диск

Задача кладёт скачанные видео на Диск с сохранением структуры папок и **удаляет
локальную копию**, поэтому объём курса не упирается в свободное место на диске.

Файл удаляется, только если он появился на Диске и совпал по размеру байт в байт.
При любой осечке локальный файл остаётся на месте. Незавершённые загрузки (рядом есть
`.part` или запись была меньше минуты назад) не трогаются.

### Токен

Токен можно подключить в интерфейсе или вписать в `.env`.

1. Создайте приложение на <https://oauth.yandex.ru/client/new/>.
2. Платформа — «Веб-сервисы», Redirect URI — `https://oauth.yandex.ru/verification_code`.
3. Доступы: `cloud_api:disk.read`, `cloud_api:disk.write`, `cloud_api:disk.info`.
4. Скопируйте `ClientID` и откройте
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`.
5. Токен будет в адресной строке после `access_token=`.

```
YADISK_TOKEN=ваш_токен
YADISK_BASE_PATH=disk:/getcourse
```

### Запуск

| Команда | Что делает |
|---|---|
| `npm run upload:check` | показывает, что будет выгружено и удалено; ничего не меняет |
| `npm run upload` | один проход |
| `npm run upload:watch` | работает непрерывно, рядом со скачиванием |
| `bash jobs/install-launchd.sh` | фоновая задача на macOS: каждые 10 минут, переживает перезагрузку |

Журнал — `logs/upload.log`, вывод фоновой задачи — `logs/upload-job.log`.
Снять задачу: `bash jobs/install-launchd.sh --remove`.

Логику удаления проверяет `node jobs/upload.test.js`: сценарии идут на заглушке, без
сети и вашего аккаунта. Записи теста попадают в `logs/upload.log`.

## Настройка

Все параметры `.env` с комментариями — в [`.env.sample`](.env.sample).

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `SCRAPPER_BASE_URL` | адрес сайта без слэша на конце | — |
| `SCRAPPER_TRAINING_CONFIG_DIR` | папка конфига, удобно указать домен | — |
| `SCRAPPER_DOWNLOAD_PATH` | куда складывать видео, относительно корня проекта | — |
| `SCRAPPER_AUTH_COOKIE_NAME`, `_VALUE`, `_DOMAIN` | вход по cookie вместо `auth-state.json` | — |
| `SCRAPPER_CONCURRENCY` | уроков одновременно | `3` |
| `SCRAPPER_DOWNLOAD_CONCURRENCY` | видео одновременно | `2` |
| `SCRAPPER_UI_PORT` | порт интерфейса | `4321` |
| `YADISK_TOKEN` | токен Яндекс Диска | — |
| `YADISK_BASE_PATH` | папка на Диске | — |
| `YADISK_INTERVAL_SECONDS` | период проверки в интерфейсе | `120` |

Настройки браузера, шаблоны поиска видео и параметры `yt-dlp` — в
[`config/config.json`](config/config.json).

## Если что-то не так

**`No video on <url>` или уроки не находятся.** Сессия getcourse живёт недолго, поэтому
первым делом войдите заново. Если не помогло, посмотрите, что видит скрапер:

```sh
node cmd/dump.js https://ваш-сайт.ru/teach/control/lesson/view/id/123
```

Команда покажет признаки страницы входа, найденные уроки и следы плеера, а HTML
сохранит в `logs/getcourse-dump.html`. Если плеер новый, добавьте шаблон в
`scrapper.parser.patterns` в `config/config.json`.

**Файл битый.** `yt-dlp` склеивает видео через `ffmpeg` — проверьте `ffmpeg -version`.

**Слишком много запросов.** Снизьте `SCRAPPER_CONCURRENCY` и
`SCRAPPER_DOWNLOAD_CONCURRENCY` до `1`.

**Интерфейс не открывается.** Скорее всего, порт занят: `SCRAPPER_UI_PORT=4455 npm run ui`.

**Войти под другим аккаунтом.** Удалите `auth-state.json` и войдите заново.

## Устройство проекта

```
ui/          веб-интерфейс и его сервер
scraper/     рендеринг, поиск уроков, запуск yt-dlp, общий конвейер для UI и CLI
jobs/        выгрузка на Яндекс Диск
cmd/         команды терминала: вход, поиск уроков, диагностика, запуск
config/      настройки и списки уроков по сайтам
lib/         MD5 для отсеивания повторяющихся видео
main.js      CLI-запуск конвейера
```

## Безопасность

- `.env`, `auth-state.json` и `yadisk-auth.json` дают доступ к вашим аккаунтам. Они в
  `.gitignore`, не публикуйте их.
- Интерфейс управляет браузером с вашей сессией, поэтому порт открыт только на
  `127.0.0.1`, а запросы с других источников отклоняются.
- `yt-dlp` запускается без шелла: заголовки уроков приходят со страницы и не могут
  выполниться как команда.
