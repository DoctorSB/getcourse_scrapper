1. Вход в аккаунт

Откроется обычное окно браузера. Входите как всегда — капча, СМС и 2FA работают. Откройте любой урок, убедитесь что доступ есть, и нажмите «сохранить сессию». Сессии GetCourse живут недолго: если уроки перестали находиться — войдите заново.

Вход по cookie

Войдите на сайт в своём обычном браузере, откройте инструменты разработчика → Application → Cookies, найдите cookie сессии и скопируйте имя и значение сюда. Это единственный способ входа, когда окно браузера открыть нельзя — например, в Docker.

5. Выгрузка на Яндекс Диск

Выгруженные видео удаляются с ноутбука — локально они не копятся. Удаление происходит только после проверки, что файл лёг на Диск и совпал по размеру. Задача работает, пока запущен этот сервис.

Токен получается на oauth.yandex.ru с доступами cloud_api:disk.read / write / info — подробности в README. Он даёт полный доступ к вашему Диску: хранится локально с правами 600, в журнал не пишется.
